## Overview

Registers `plsr.Dealerships` — showrooms, sales, test drives, rentals, government fleets, and donor-exclusive dealerships, each its own client/server pair sharing config under `config/`.

---

## Dependencies

- `pulsar_core` — framework core
- `pulsar_vehicles` — actual vehicle spawning/ownership backs every sale, rental, and test drive here
- `pulsar_pwnzor` — anti-cheat check loaded alongside every resource
